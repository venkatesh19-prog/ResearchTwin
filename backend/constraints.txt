# Semantic embeddings run on ONNX Runtime instead of torch: the torch import
# alone costs ~190 MB of RSS and the sentence-transformers stack ~405 MB,
# which does not fit the 512 MB Render Free instance. In WSL Linux (not Render)
# the full ONNX recommendation workflow peaked at 412.2 MB RSS. The ONNX graph
# uses the same all-MiniLM-L6-v2 weights and reproduces its vectors within
# float32 rounding (max similarity delta 3.6e-07 on the directory).
#
# Test-only and build-only packages (pip, setuptools, pytest, pluggy, iniconfig)
# are intentionally absent. Do not upgrade a pin without re-running the full
# backend suite and the model-bundle tests in a fresh environment.
